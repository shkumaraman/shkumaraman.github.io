PhotoShare & Live Media Streaming

PhotoShare combines private cloud sharing with instant direct peer-to-peer folder streaming. Both methods use the same simple 5-digit code system.

How the Unified "View" Tab Works

There is only one single View tab for all viewers. When you enter any 5-digit code:

  1. Cloud Check: The app checks if the code belongs to photos uploaded to the server. If found, your gallery loads immediately.
  2. Direct Peer-to-Peer Stream: If the code is not on the cloud server, it automatically connects to the host's device in real time via WebRTC. No extra database records or storage nodes are used.
  3. Creator Activity Sync: When streaming via live P2P, the host screen shows in real time which media file the viewer is currently looking at or playing.
  4. Broad Format Support: The live stream supports photos (JPG, PNG, WEBP), animated GIFs, video files (MP4, MKV, WEBM, MOV), and audio files (MP3, WAV, OGG, M4A, AAC).

Sharing Modes Overview

  • Upload Photos: Upload up to 10 photos. Files are safely stored with selectable expiry times (up to 24 hours) and auto-deleted.
  • Live: Select any media folder from your device and click Broadcast. Files are never stored on any server; data flows directly from your device to the viewer's screen.

Note: During live P2P streaming, the host tab must stay open in the browser for the viewer to stream files.
